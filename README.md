## 📌 About the Internship

This repository documents my learning journey and practical work during the **IBM SkillsBuild Data Analytics with AI Internship 2026**, offered in collaboration with **AICTE** and BharatCares.

The internship is an industry-focused learning experience covering **Data Analytics, Data Preprocessing, Exploratory Data Analysis, Predictive Analytics, Machine Learning, Data Visualization, and AI-Driven Insights**.

The program includes guided learning, expert-led masterclasses, hands-on activities, and a final project.

**Internship Duration:** 17 August 2026 – 30 September 2026
**Internship ID:** IBMUEDA0305
**Internship Type:** Virtual
**Internship:** Unpaid

---

## 🎯 Internship Objectives

The key objectives of this internship are to:

* Build foundational knowledge in Data Analytics and Data Science
* Understand data cleaning, wrangling, and preprocessing
* Perform Exploratory Data Analysis (EDA)
* Understand predictive analytics and predictive modeling
* Learn fundamentals of Machine Learning
* Explore regression and classification techniques
* Understand Decision Trees
* Learn unsupervised learning and clustering
* Develop data visualization skills
* Work with Power BI / Tableau
* Generate AI-driven insights from data
* Apply analytical concepts to a real-world project
* Develop problem-solving and critical-thinking skills
